# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an security report to the repository maintainers. All security vulnerabilities will be addressed promptly.

## Security Procedures

1. **Disclosure Protocol**: Please do not open public issues reporting security vulnerabilities.
2. **Investigation**: Vulnerabilities will be verified and patched in a dedicated development branch.
3. **Release**: Patched versions will be released with appropriate notes once verified.
